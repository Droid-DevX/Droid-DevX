# Featured Projects

## [Vision-Free Robotic Manipulation](https://github.com/Droid-DevX/Robotic_Manipulation_Using_PPO_PID)

* Vision-free pick-and-place control for a 7-DOF Franka Panda
* Hierarchical PPO + PID control in MuJoCo
* Compared learning-based control against classical IK + PID

## [Quadruped Locomotion](https://github.com/Droid-DevX/Quadruped_Walking)

* PPO-based locomotion controller for Unitree A1
* Joint-level PD torque control with PyBullet
* Extended to uneven terrain using curriculum learning
  
## [Fault-Tolerant Crazyflie Control](https://github.com/Droid-DevX/)

* Goal-conditioned SAC for actuator fault-tolerant hover control
* Custom Gymnasium + PyBullet environment with motor fault injection
* Domain-randomized control evaluated against PID and SAC baselines

  
## [Vectorless RAG](https://github.com/Droid-DevX/VectorlessRAG)

* Vector-database-free document Q&A using BM25 retrieval
* Section-aware chunking and deterministic reranking
* React + FastAPI + Groq deployment with source citations
